# Задачник — Discrete Mathematics

Учебный тренажёр для подготовки к экзамену, адаптированный для компьютера и телефона.

- **Sample Final Test:** 131 задача из Pre-Final Fall 2020, с переводом и проверенным разбором.
- **Final Test:** 20 новых задач, ориентировочно сложнее образца.
- Решения открываются после верного ответа. Ошибочный ответ позволяет попробовать снова.
- Фильтр тем, навигация и отдельное локальное сохранение прогресса для двух тестов.
- Отдельная вкладка «Разборы задач»: все 151 решения доступны без проверки ответа.
- Поиск по номеру и условию, фильтры темы и сложности, маршруты «Базовые методы» и «К 18/20».
- Расширенные объяснения сложных пересечений, систем сравнений и рекурсий. Чтение не меняет результат теста.
